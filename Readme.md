# Irohole

P2P remote-control over Iroh (QUIC). Currently it has pretty basic frame
that many plugin can sepak that can be TCP, UART, input devices, screen,
phones, ESP32 bridge, or anything we can custom build.

> This project is still WIP and experimental 

### Experimenting with: 

* [ ] TCP tunnel as a plugin
* [ ] plugin for input 
* [ ] plugin for screen
